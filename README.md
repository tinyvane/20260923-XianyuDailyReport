# 闲鱼商品监控日报

本机运行的闲鱼监控工具。界面参照本地 `参考页面/闲鱼日报.png`；支持从当前 Chrome 登录会话读取关注卖家、选择重点对象、保存商品快照，并按 1 小时至 30 天窗口生成日报。参考图含客户标识，保留本地，不提交到 GitHub。

## 首次设置

1. Windows 双击 `start.bat`。首次运行会安装 Python 依赖，然后在**正常使用的 Google Chrome** 中打开 `http://127.0.0.1:5055/`。启动器不会创建独立浏览器资料，也不会打开 Edge。
2. 在 Chrome 地址栏输入 `chrome://extensions`，开启“开发者模式”，点击“加载已解压的扩展程序”，选择本项目的 `chrome-extension` 文件夹。只需安装一次。刷新日报页面。
3. 在同一个 Chrome 中打开 [闲鱼官网](https://www.goofish.com/) 并自行登录；程序不接收密码或 Cookie。回到日报页面点击“连接现有 Chrome”和“检查登录”。

## 采集

1. 在已登录的闲鱼 Chrome 标签页进入自己的关注列表，回到日报点击“导入 Chrome 关注页”。导入的卖家先作为候选名单，需勾选需要重点监控的对象。也可以粘贴卖家个人主页链接手动添加。
2. 点击“立即采集”。扩展在同一 Chrome 资料中读取卖家当前可见的商品页面；数据写入本机 `data/report.sqlite3`。每位卖家每次最多读取 40 件可见商品。
3. 首次采集只是基线。经过所选对比时长后再次采集，才会显示浏览和想要增长；缺少前后快照的商品显示未知。
4. 设置中可开启“打开日报后自动采集”和定时采集。**日报标签页与本地程序需保持运行**；关闭后停止，下次打开日报会恢复。

## 数据与限制

- 当前版本读取官方网页中的可见指标；缺字段、登录过期、页面验证或无法识别商品时会跳过并报告，不会填充虚构的零值。
- 登录资料始终由原有 Chrome 管理。扩展把可见的卖家链接和商品指标交给本机日报，不复制 Cookie 到数据库或 Git。
- 闲鱼网页结构可能改变。此版本的 Chrome 扩展尚需在用户的真实关注页和商品页验收；通过代码与合成数据检查不能代替真实账号验证。
- 本机服务仅监听 `127.0.0.1:5055`，无远程生产部署。`data/` 已被 Git 忽略；备份时先关闭程序，再复制该目录到私人存储。

手动启动命令：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe launch.py
```
