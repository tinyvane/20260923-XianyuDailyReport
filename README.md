# 闲鱼商品监控日报

本机运行的闲鱼监控工具。界面参照本地 `参考页面/闲鱼日报.png`；支持从已登录的 Edge 或 Chrome 读取“我的收藏”中的有效宝贝，选择重点商品与卖家，保存商品快照，并按 1 小时至 30 天窗口生成日报。参考图含客户标识，保留本地，不提交到 GitHub。

## 首次设置

1. Windows 双击 `start.bat`，本地日报地址为 `http://127.0.0.1:5055/`。默认选择 **现有 Edge · 扩展**，直接使用 Edge 中已经登录的闲鱼标签页。在 Edge 打开 `edge://extensions`，开启“开发者模式”，加载本项目的 `chrome-extension` 文件夹，再刷新日报页面。扩展只需安装一次。
2. 如需使用 Chrome，在顶部“浏览器”选择 **Chrome · 扩展**，在 Chrome 的 `chrome://extensions` 同样加载扩展。也可选择 **固定 Edge · 已扫码**：它复用 `data/browser-profile/` 独立资料；此资料与平常使用的 Edge 登录状态分开，过期后需在该窗口重新登录。
3. 在所选浏览器打开 [闲鱼官网](https://www.goofish.com/) 并自行登录；程序不接收密码。点击“检查登录”确认页面已登录。

## 采集

1. 在所选浏览器打开闲鱼“我的收藏 → 有效宝贝”页面，回到日报点击“导入收藏商品”。Edge 会尝试在同一资料窗口直接打开该页面。导入的商品默认选中，可在监控名单中逐件取消；最多读取当前页面可见或加载出的 200 件。Chrome 扩展需在已打开的收藏页使用。
2. 点击“立即采集”。程序使用所选浏览器的同一登录资料读取选中商品的详情，识别卖家并保存价格、浏览量、想要量等页面可见指标；商品卖家进入候选名单。可以单独勾选卖家主页或手动添加主页链接，以监控卖家其他可见商品。每位卖家每次最多读取 40 件。数据写入本机 `data/report.sqlite3`。
3. 首次采集只是基线。经过所选对比时长后再次采集，才会显示浏览和想要增长；缺少前后快照的商品显示未知。
4. 设置中可开启“打开日报后自动采集”和定时采集。**日报标签页与本地程序需保持运行**；关闭后停止，下次打开日报会恢复。

## 数据与限制

- 当前版本读取官方网页中的可见指标；缺字段、登录过期、页面验证或无法识别商品时会跳过并报告，不会填充虚构的零值。
- 固定 Edge 登录资料保存在本机 `data/browser-profile/`；现有 Edge 和 Chrome 的登录资料仍由各自浏览器管理。扩展只把可见的卖家链接和商品指标交给本机日报；Cookie 不写入数据库或 Git。
- 闲鱼网页结构可能改变。收藏列表、商品详情和卖家主页以实际可读内容为准；没有商品链接、卖家身份或指标时明确报告失败，不伪造数据。真实账号采集结果需在账号中验收。
- 本机服务仅监听 `127.0.0.1:5055`，无远程生产部署。`data/` 已被 Git 忽略；备份时先关闭程序，再复制该目录到私人存储。

手动启动命令：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe launch.py
```
