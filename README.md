# 闲鱼商品监控日报

本机运行的闲鱼监控工具。界面参照本地 `参考页面/闲鱼日报.png`；支持从已登录的 Edge 或 Chrome 读取“我的收藏”中的有效宝贝，选择重点商品与卖家，保存商品快照，并按 1 小时至 30 天窗口生成日报。参考图含客户标识，保留本地，不提交到 GitHub。

## 首次设置

1. Windows 双击 `start.bat`，本地日报地址为 `http://127.0.0.1:5055/`。默认选择 **现有 Edge · 扩展**，直接使用 Edge 中已经登录的闲鱼标签页。在 Edge 打开 `edge://extensions`，开启“开发者模式”，加载本项目的 `chrome-extension` 文件夹，再刷新日报页面。扩展只需安装一次。
2. 如需使用 Chrome，在顶部“浏览器”选择 **Chrome · 扩展**，在 Chrome 的 `chrome://extensions` 同样加载扩展。也可选择 **固定 Edge · 已扫码**：它复用 `data/browser-profile/` 独立资料；此资料与平常使用的 Edge 登录状态分开，过期后需在该窗口重新登录。
3. 在所选浏览器打开 [闲鱼官网](https://www.goofish.com/) 并自行登录；程序不接收密码。点击“检查登录”确认页面已登录。

## 采集

1. 在所选浏览器打开闲鱼“我的收藏 → 有效宝贝”页面，回到日报点击“导入收藏商品”。导入的商品都是候选，**默认不勾选**；在“候选商品 · 勾选重点”中手动勾选要监控的几件。可按商品名或 ID 搜索、按状态筛选，再批量选中当前结果。单次导入最多识别当前页面可见或加载出的 200 件；Edge 扩展需在已打开的收藏页使用。
2. 勾选重点商品后，程序立即尝试读取该商品详情中的卖家名字和主页，并将其关联到“重点关注卖家”，**不需要手动输入卖家 URL**。详情暂时无法加载时，勾选会保留并显示失败状态；可稍后点击“立即采集”重试。已识别卖家会随重点商品动态进入或退出日报。
3. 点击“立即采集”时，只读取勾选商品并保存价格、浏览量、想要量等可见指标。下方卖家复选框用于**额外监控该店其他商品**；只有单独勾选后才会遍历店铺，每位卖家每次最多读取 40 件。数据写入本机 `data/report.sqlite3`。
4. 首次采集只是基线。经过所选对比时长后再次采集，才会显示浏览和想要增长；缺少前后快照的商品显示未知。
5. 设置中可开启“打开日报后自动采集”和定时采集。**日报标签页与本地程序需保持运行**；关闭后停止，下次打开日报会恢复。

## 数据与限制

- 当前版本读取官方网页中的可见指标；缺字段、登录过期、页面验证或无法识别商品时会跳过并报告，不会填充虚构的零值。先前采集成功的候选商品会保留详情和快照，勾选后可直接进入日报；仍需再次采集才会得到新的对比点。
- 固定 Edge 登录资料保存在本机 `data/browser-profile/`；现有 Edge 和 Chrome 的登录资料仍由各自浏览器管理。扩展只把可见的卖家链接和商品指标交给本机日报；Cookie 不写入数据库或 Git。
- 闲鱼网页结构可能改变。收藏列表、商品详情和卖家主页以实际可读内容为准；没有商品链接、卖家身份或指标时明确报告失败，不伪造数据。已登录 Edge 实测导入 200 件候选商品，其中 25 件详情有效、24 件明确失效，其余未完成或未能加载详情；请只勾选实际要监控的商品，再验证这些商品能否读取。
- 本机服务仅监听 `127.0.0.1:5055`，无远程生产部署。`data/` 已被 Git 忽略；备份时先关闭程序，再复制该目录到私人存储。

手动启动命令：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe launch.py
```
